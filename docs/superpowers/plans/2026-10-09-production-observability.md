# Safe operational evidence

Issue 13 acceptance is the approved brief. Add fixed-label process request,
latency, admission, readiness and unknown-usage observation metrics behind a
separate operator bearer credential. Ordinary identities cannot scrape global
metrics. Application-owned reservation phase gauges query only aggregate counts
under existing bounded read admission and database deadlines.

Generate request IDs in the host; never trust inbound correlation headers. Log
trusted run UUIDs and keyed tenant/call references without prompts, credentials,
arbitrary routes, errors or provider payloads. Preserve context in admitted
workers. Unknown accounting observations are process observations rather than
a durable global unknown balance; use owner-scoped durable evidence for recovery.

Engine errors retain whitelisted phase, return code, timeout/outcome and bounded
fixed categories; captured command arguments/stderr remain private. Unknown
creation cleanup stays fail-closed. Test secret sentinels, bounded metric labels,
separate operator authentication, saturation/readiness faults and unknown usage
on real PostgreSQL 16/18. Add the lane to required audit acceptance and its count
contract. Keep remote monitoring activation separate from locally tested rules.
