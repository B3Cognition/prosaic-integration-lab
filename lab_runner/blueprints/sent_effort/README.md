# Sent reasoning-effort V1

Copy this blueprint without making a call. Runtime0.9.18 is required; use the
Lab release's complete manifest/checksums, Core0.5.0 and Harness0.9.12. The default
endpoint is an intentionally unused loopback port. `python host.py --live` is an
explicit one-call opt-in after configuring your own endpoint/model; tests use
credential-free synthetic providers and fake CLI processes only.

`effort_report(result)` shows requested artifact effort, the original profile
default and actual sent controls/format for each observed attempt. The source is
Runtime's public `reasoning_effort_v1` metadata. A sent HTTP request or launched
CLI does not prove delivery, receipt or compliance. `provider_confirmation` is
always `not_observed`. Binary thinking-on implies no neutral tier; explicit none,
false and omission differ. Native inner calls/vendor settings remain unobserved.

Histories retain tool continuations, repairs, adapter retries and pool fallback.
At most64rows/32768JSONbytes are retained; omission/unknown counts and incomplete
histories remain explicit. Missing old receipt data means unavailable, not zero.
Private saved Result receipts retain traces across pause/reopen/no-call recovery.
HTTP provider_call_id joins existing recorder call IDs without DDL. Labels and
usage are diagnostic, never permission, retry consent or an invoice.

`workflow` supplies a finite two-call, approval-gated Harness example. Pass only
trusted host identity/accounting context; never model/client authorization. Use
`public_view` as a minimal allowlist, never return operator state/receipts/raw
SDK result metadata to clients. No prompts/headers/keys/paths are copied into the
new trace; the pre-existing full result may still contain private diagnostics.

See the repository's sent-effort guide and release notes for synthetic/real-stack
qualification and limitations. No live-provider certification is implied.
