# Lab 0.9.12 — context-pack acceptance

Adopts public Runtime **0.9.19**, Harness **0.9.13** and Harness PostgreSQL
**0.4.2**, retaining original Core **0.5.0** and recorder **0.3.0** artifacts.
Complete manifests bind actual public wheel URLs, source commits and SHA256 hashes.
Earlier active manifests, packaged profiles and benchmark freezes remain archived.

The [context-pack lane](https://github.com/B3Cognition/prosaic-integration-lab/blob/v0.9.12/docs/context-packs.md) covers Markdown agent defaults and
workflow-node overrides, accepted service lookup records, scoped citations and
actual deferred reads, absent/partial/contradictory evidence, revocation and
foreign-scope refusal, restart adoption, default capacity and denied worker DDL.
Normal released acceptance now requires all 12 cases in every architecture/database
cell. Explicit candidates retain complete lineage and installed-byte verification.

Runtime accepts a bounded model projection with separately retained private guard
facts. Selecting model context does not silently change validation authority.
Harness owns scoped capture, accepted-record resolution and frozen context bindings;
applications own authorization and explicit schema migrations. Pack-free callers,
legacy saved records and prior published SDK trains keep their existing paths.
New context-pack records require capable readers; mixed trains are refused.

Release gates retain exact-source and isolated wheel/rebuilt-source consumers,
frontend/browser/native checks, all four Linux AMD64/ARM64 × PostgreSQL 16/18
ordinary cells, all four installed feature/rule/database cells and both reasoning
jobs. All required context-pack cases must pass with no skips and verified cleanup.
A verified-head merge must preserve the tested tree, followed by independent
post-merge checks. Publish only original qualified CI wheel/source bytes with
checksums and sanitized provenance, then verify anonymous public downloads and
fresh installed consumers. Earlier releases and assets remain immutable.

Qualification uses synthetic loopback responses and owned fixtures. It demonstrates
SDK contracts and persistence behavior, not model answer quality or token savings.
No paid or live inference is part of this release.
