## Portable Windows fixtures with unchanged guards

After the logging fix, Windows completed and exposed two fixture failures.
SQLite transaction contexts do not close their connections; wrap each fixture
connection in closing(...) as well as its original transaction context so the
later unlink has no open handle. Keep every invalid-store and health assertion.

The real-worker fixture's all-connect guard blocked Windows asyncio's own TCP
wakeup socketpair during LanceDB initialization. CPython's actual fallback
reproduced that failure locally. Reserve one owned stdlib pair before any
Castle/LanceDB import, then keep the guard throughout all imports and requests;
restore the original socketpair factory on first use. Direct loopback and
external connect probes must still fail before and after requests. Both native
and forced-fallback cases retain every original byte/scope/engine/no-write
assertion. These fixture fixes change no product code or network allowlist.
Both final Windows jobs passed all three formerly failing cases.

## SUE and remaining release requirements

Assuming SUA means SUE, it has not been removed and does not depend on SOAR.
The [SUE use and Prosaic fit guide](https://github.com/B3Cognition/cognitive-castle/blob/58f4242080212c2bebcca0c685af0f5e1090aa94/docs/prosaic-sue.md)
documents CLI/MCP entry points and the existing pure incremental engine. A
separate optional review consumer can reuse that policy over exact frozen
evidence. Runtime owns each model attempt; Harness owns accepted state, retries,
budgets and resume. Do not run an entire Castle SUE dialogue inside one Runtime
attempt. No SUE integration is implemented by this memory release.

Public Runtime 0.9.8 lacks `custom_tool_errors_v1`; model-tool registration stays
capability-gated. This release qualifies host snapshots/resume. Clear all final
checks, confirm index/Trusted Publisher ownership for both distributions and
obtain explicit publication authorization. The existing publishing workflow
covers only the worker. No package publication, tag, automatic capture, memory
activation or SUE/SOAR quality certification is included.
