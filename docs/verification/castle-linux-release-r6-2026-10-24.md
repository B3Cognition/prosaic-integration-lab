## SUE and remaining release requirements

Assuming SUA means SUE, it has not been removed and does not depend on SOAR.
The [SUE use and Prosaic fit guide](https://github.com/B3Cognition/cognitive-castle/blob/76030d3f7aeddb7fbb93ad10be640b1ab1c07644/docs/prosaic-sue.md)
documents CLI/MCP entry points and the existing pure incremental engine. A
separate optional review consumer can reuse that policy over exact frozen
evidence. Runtime owns each model attempt; Harness owns accepted state, retries,
budgets and resume. Do not run an entire Castle SUE dialogue inside one Runtime
attempt. No SUE integration is implemented by this memory release.

Public Runtime 0.9.8 lacks `custom_tool_errors_v1`; model-tool registration stays
capability-gated. This release qualifies host snapshots/resume. Clear all final
checks, confirm index/Trusted Publisher ownership for both distributions and
obtain explicit publication authorization. The existing publishing workflow
covers only the worker. No package publication, tag, automatic capture, memory
activation or SUE/SOAR quality certification is included.
